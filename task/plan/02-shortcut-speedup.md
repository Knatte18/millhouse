## Batch Scope

This batch replaces the PS1 shortcut-wrapper template and updates `_shortcuts.write_all` to accept a required `latest_path` parameter. Together, these changes eliminate two of the three startup overhead layers: the `Get-ChildItem | Sort-Object` scan and the `uv run --project` project-resolution step. The new template calls `uv run --active "<SCRIPT_PATH>"` where `<SCRIPT_PATH>` is a hardcoded absolute path to the script in the plugin cache; the venv is activated once at shell startup (handled by batch 04). The test suite for `_shortcuts` is updated in the same batch to preserve test coverage. The commit message for card 2 must reference the `uv run --project` vs `uv run --active` timing delta from `task/benchmark-notes.md`.

Batch-local decisions: see `merge-fixes-1-and-3` and `write-all-required-latest-path` in discussion.md § Decisions.
