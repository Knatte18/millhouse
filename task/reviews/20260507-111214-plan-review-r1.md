## Findings

### [BLOCKING] Stuck cleanup leaves working tree dirty before branch switch
**Location:** Batch 3, Card 8 — stuck cleanup helper requirement  
**Issue:** The stuck cleanup sequence is `git clean -fd task/` → `git checkout <parent_branch>`. `git clean -fd task/` removes untracked files in `task/` only. If the implementer sub-session modified tracked source files (e.g. `src/foo.py`) without committing before getting blocked, `git checkout <parent_branch>` will abort with "Your local changes to the following files would be overwritten by checkout" — source files exist on both branches; git refuses to overwrite uncommitted edits. This leaves mill-autofix in an unrecoverable state mid-loop.  
**Fix:** Prepend `git reset --hard HEAD` to the stuck cleanup sequence so uncommitted tracked changes are discarded before the branch switch: `git reset --hard HEAD`, `git clean -fd task/`, `git checkout <parent_branch>`, `rm .millhouse/active.slug.md`.

### [NIT] Short-form CLI invocations in Card 8 requirements may produce wrong SKILL.md
