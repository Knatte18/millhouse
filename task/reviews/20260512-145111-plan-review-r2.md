**Location:** Batch 2, Card 3
**Issue:** The Holistic section (steps 3, 3.5, and 5) contains multi-line shell commands where `uv run --project "${PLUGIN_ROOT}" \` occupies its own line and the script path continues on the next line. Card 3's Shape A/B rules only describe the single-line form; the implementer must infer restructuring.
