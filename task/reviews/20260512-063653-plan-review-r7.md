## Findings

### [BLOCKING] Card 18 patches wrong worktree removal function
**Location:** Batch 3 / Card 18, test 1
**Issue:** Card 18 instructs patching `_worktree.remove`, but `_apply_worktree_record` (which card 15 specifies as the call target) calls `_worktree.remove_safe`, not `_worktree.remove`. Assertion "(c) a worktree-remove call was made" checks the never-called `remove` mock and fails. `remove_safe` runs unguarded via the subprocess mock, then the mock-assertion fails, blocking batch 3's `verify:`.
**Fix:** Replace `patch("mill_cleanup._worktree.remove", ...)` with `patch("mill_cleanup._worktree.remove_safe", ...)` in test 1.

### [NIT] Card 20 portal assertion references non-existent fixture state
**Location:** Batch 4 / Card 20
**Issue:** "add positive assertion that the portal junction still exists" — `_setup_trio` never creates `container/portals/<slug>`. The assertion `assert (container / "portals" / slug).exists()` would fail immediately.
**Fix:** Either skip the portal assertion (fixture has none) or add portal creation to `_setup_trio` before the assertion.

### [NIT] Card 17 test 1 / Card 12 — double-implementation of `_mock_branch_run` tag branch
**Location:** Batch 3 / Cards 12 and 17
**Issue:** Card 12 installs the `"tag" in argv and "-l" in argv` branch in `_mock_branch_run` as a default. Card 17 test 1 then says "extend `_mock_branch_run`" for the same behavior, risking a second implementation or confusion about where the default lives.
**Fix:** Card 17 test 1 should read "uses the default tag behavior already installed by card 12 — no extension to `_mock_branch_run` needed for this test."

### [NIT] Card 4 inconsistent final test name convention
**Location:** Batch 1 / Card 4
**Issue:** The specified final-state set mixes conventions: `test_slug_from_branch_done` (no `phase_` prefix) alongside `test_slug_from_branch_phase_abandoned` and `test_slug_from_branch_phase_none` (with `phase_` prefix). All three are rewrites of the same "non-active phase now succeeds" class of tests.
**Fix:** Either drop `phase_` from all three (`test_slug_from_branch_done`, `test_slug_from_branch_abandoned`, `test_slug_from_branch_none`) or add it to all three for consistency.
