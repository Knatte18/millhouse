### [BLOCKING] Dataclass field ordering TypeError — Card 11
**Location:** Batch 3 / Card 11
**Issue:** Card 11 places `to_reap_pr: list[SlugRecord] = field(default_factory=list)` (has default) between `to_remove_abandoned` and `to_reset_home` (both have no defaults). Python raises `TypeError: non-default argument 'to_reset_home' follows default argument` at class-definition time, breaking every import of `millpy-cleanup.py` and causing all `test-cleanup.py` tests to error on load.
**Fix:** Declare `to_reap_pr` as the last field in `CleanupPlan` (after `to_report`). All existing callers use keyword arguments so field-position change is backward-compatible; the `field(default_factory=list)` default remains mandatory.
