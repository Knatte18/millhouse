## Findings

### [BLOCKING] Card 20 archive-tag push: hub has no origin remote
**Location:** Batch 4 / Card 20  
**Issue:** Card 20 requires `subprocess.run(["git", "-C", str(hub), "push", "origin", f"archive/{slug}"], check=True)`, but `_setup_trio` initialises `hub` as a bare `git init` with no remote — `check=True` will raise `CalledProcessError` and fail the test immediately. The existing squash-commit steps in `test-merge.py` have no hub push either, confirming hub has no origin.  
**Fix:** Drop `check=True` → `check=False` for the push line (the test assertion only checks local tag existence via `git tag -l`), or extend `_setup_trio` to create a `hub.git` bare remote and configure hub's origin to match — without this change the test will always fail when run.
