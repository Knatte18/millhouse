## Findings

### [NIT] `_filter_open_worktrees` exception handler too narrow
**Location:** Batch 2 / Card 3
**Issue:** The per-entry config-load catch is `except SystemExit:`, but `_load_config` raises `yaml.YAMLError` (malformed YAML) and `OSError` (unreadable file) — neither is a `SystemExit` subclass, so those cases propagate uncaught to `main()`.
**Fix:** Use `except (Exception, SystemExit):` to match the stated intent ("on any exception during config load, fall back").
