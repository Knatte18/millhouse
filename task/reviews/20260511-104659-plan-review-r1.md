### [NIT] Malformed YAML fixture `: : :` may silently parse
**Location:** Batch 1 / Card 2, `test_probe_three_states` "malformed" sub-case
**Issue:** `: : :` can be interpreted by PyYAML as a block mapping `{None: {None: None}}` and may not raise `yaml.YAMLError`. If it parses cleanly, `probe` returns `PRESENT` and the sub-case assertion fails on the first run.
**Fix:** Use an unambiguously invalid YAML string such as `key: [` (unclosed flow sequence) or `- valid\n  - wrong: indent\nbad:` instead. Implementer should verify the chosen string raises `yaml.YAMLError` via a quick REPL check before committing.
