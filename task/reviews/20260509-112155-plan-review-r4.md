## Findings

### [NIT] M2 test fixture omits explicit container_path patch
**Location:** Batch 2, Card 3 (M2 and M2+sub test cases)
**Issue:** The new `resolve_path` calls `_paths.resolve_container_path(git_root)` internally, which is not patched. With the subprocess mock returning a branch name as fake `--git-common-dir` output, `resolve_container_path` computes `container_path = git_root` rather than the real container. Tests pass because in-place detection fires before the worktree-dir fallback, but the behaviour is coincidental rather than designed.
**Fix:** Add `unittest.mock.patch("_paths.resolve_container_path", return_value=container_path)` alongside the other `_paths.*` patches in the M2/M2+sub test cases.

### [NIT] Trampoline subprocess-recording mechanism under-specified
**Location:** Batch 3, Card 5
**Issue:** Card 5 says "Save the recorded commands to a temp file the test can read back" but does not specify the file format, how the path is injected into the trampoline, or how the test parses it. The implementer must infer the entire recording approach (e.g., a JSON list at a fixed `tmp / "git_commands.json"` path, embedded in the trampoline script at creation time).
**Fix:** Add one sentence specifying the file path convention and format, e.g.: "Write `tmp / '_git_calls.json'` as a JSON array of argv lists; embed the path as a raw string literal in the trampoline at `_make_trampoline` call time."

## Verdict

APPROVE — no blocking defects; two NITs on test robustness and specification completeness.
