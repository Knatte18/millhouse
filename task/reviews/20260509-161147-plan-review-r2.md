## Findings

### [BLOCKING] Card 13 migration-warning test asserts contradictory behavior
**Location:** Batch 2 / Card 13 — `test-review-common.py` migration-warning test
**Issue:** The requirement says "Also assert the merged cfg returned does NOT contain `cfg['review']` after the merge" but card 7's behavior spec explicitly states `load_config` returns the deep-merged cfg unchanged — meaning the overlay's `review:` key IS present in the merged result via `_deep_merge`. The parenthetical (" the assertion is that the warning fires, not that the orphan is removed") contradicts the preceding instruction rather than clarifying it. An implementer following the literal sentence will write `assert "review" not in merged_cfg`, which fails every time.
**Fix:** Remove the "does NOT contain" assertion clause entirely. The test should assert only that (a) stderr contains a warning mentioning the overlay path and the key `review`, and (b) the returned cfg is otherwise usable — it is acceptable that `cfg["review"]` is present as a harmless orphan from the deep-merge.

### [NIT] Cards 4 and 14 list `run-all.py` edits that are no-ops
**Location:** Batch 1 / Card 4 (Edits: run-all.py); Batch 2 / Card 14 (remove deleted test entry)
**Issue:** `run-all.py` discovers tests via `HERE.glob("test-*.py")`. New test files (`test-reviewers.py`, `test-reviewer-single.py`) are picked up automatically; deleting `test-reviewer-modules.py` removes it automatically. No source change is needed in either card.
**Fix:** Remove `run-all.py` from Card 4's Edits list and remove the instruction in Card 14 to "Remove the corresponding entry from … run-all.py".

### [NIT] Card 9 batch skip `rounds == 0` not spelled out in rewiring details for `run()`
**Location:** Batch 2 / Card 9 — `_review_plan.py`
**Issue:** The requirement states "Skip semantics — `reviewer is None OR rounds == 0` — applies to both scopes" but the concrete rewiring steps only describe replacing the `reviewer is None` check for the batch scope in `run()`. The `rounds == 0` half of the batch skip condition is not mentioned in the step-by-step replacement text, leaving it implicit.
**Fix:** Add a sentence to the rewiring steps specifying that `holistic_only` is set to `True` when `batch_reviewer_name is None OR cfg["roles"]["plan-review"]["batch"]["rounds"] == 0`, mirroring the explicit treatment of `reviewer is None`.

### [NIT] Card 13 does not explicitly address removal of `load_reviewer` test in `test-review-common.py`
**Location:** Batch 2 / Card 13 — `test-review-common.py`
**Issue:** After card 7 removes `load_reviewer` from `_review_common`, the existing test `load_reviewer: nonexistent -> ReviewError` and its import will cause an `ImportError` at test-load time. Card 13 instructs changing `from _review_common import load_reviewer` usages but does not explicitly identify the standalone test case that exercises it — the equivalent coverage already exists in `test-reviewers.py` subtest 11.
**Fix:** Add an explicit bullet to card 13's `test-review-common.py` instructions: remove the `load_reviewer` import line and delete the corresponding test case (coverage is provided by `test-reviewers.py` subtest 11).
