## Batch Scope

Establish the uv project (`pyproject.toml`), the new PS1 shortcut-wrapper template, and the updated `_shortcuts.py` writer. This batch produces the foundational artefacts every later batch consumes: the `--project` target for `uv run`, the wrapper template that mill-setup will materialise into `.millhouse/`, and the helper that drives that materialisation. No SKILL.md changes here — those happen in batches 03 and 04 once the foundation exists. The deletion of the old `shortcut-wrapper.py` template happens in card 2 so the repo never has both templates side-by-side.

## Cards

### Card 1: Create `plugins/mill/pyproject.toml`

- **Reads:**
  - `plugins/mill/scripts/_active.py`
  - `plugins/mill/scripts/_config.py`
  - `plugins/mill/scripts/_wiki.py`
  - `discussion.md`
- **Modifies:** none
- **Creates:**
  - `plugins/mill/pyproject.toml`
- **Requirements:** Create a minimal `pyproject.toml` at `plugins/mill/pyproject.toml` declaring an uv-compatible project. Required fields: `[project]` block with `name = "mill"`, `version = "0.1.0"`, `requires-python = ">=3.10"`, `dependencies = ["pyyaml>=6.0"]`. Add `[tool.pytest.ini_options]` with `pythonpath = ["scripts"]` so pytest discovers helpers without external PYTHONPATH. PyYAML is the only non-stdlib runtime dependency (verified via grep across `plugins/mill/scripts/`). After writing, smoke-check by running `uv run --project plugins/mill python -c "import yaml; print(yaml.__version__)"` — must exit 0 and print a version string.
- **Commit:** `chore(mill): add pyproject.toml for uv migration`

### Card 2: Replace shortcut-wrapper template (Python → PS1)

- **Reads:**
  - `plugins/mill/templates/shortcut-wrapper.py`
  - `plugins/mill/scripts/_render.py`
  - `plugins/mill/scripts/_shortcuts.py`
  - `discussion.md`
- **Modifies:** none
- **Creates:**
  - `plugins/mill/templates/shortcut-wrapper.ps1`
- **Requirements:** Create a new PS1 template at `plugins/mill/templates/shortcut-wrapper.ps1` matching the shape in discussion.md § "PS1 template shape". The template must use the `<SCRIPT>` token (matches the existing `_render.render` substitution mechanism — `_render` does verbatim `<TOKEN>` → value substitution). The script must (1) compute `$cache = "$HOME\.claude\plugins\cache\millhouse\mill"`, (2) pick the latest version dir via `Get-ChildItem $cache -Directory | Sort-Object Name -Descending | Select-Object -First 1`, (3) error out cleanly if no version dirs exist, (4) invoke `uv run --project $latest "$latest\scripts\<SCRIPT>.py" @args`. Do NOT set `$env:PYTHONPATH` in the wrapper — it is a global Windows user env var (set by mill-setup Phase 4.7). Include a leading comment `# Wrapper for <SCRIPT> — generated by mill-setup Phase 4.7. Do not edit manually — re-run mill-setup.`. Also delete `plugins/mill/templates/shortcut-wrapper.py` in this same commit (`git rm`) — the old `.py` template is replaced wholesale, no transitional period.
- **Commit:** `feat(mill): replace shortcut-wrapper template with PS1`

### Card 3: Update `_shortcuts.py` to write PS1 wrappers and clean up legacy `.py` wrappers

- **Reads:**
  - `plugins/mill/scripts/_shortcuts.py`
  - `plugins/mill/scripts/_render.py`
  - `plugins/mill/templates/shortcut-wrapper.ps1`
- **Modifies:**
  - `plugins/mill/scripts/_shortcuts.py`
- **Creates:** none
- **Requirements:** Update `_shortcuts.py` to write `.ps1` files instead of `.py`. Specifically: (1) change `_TEMPLATE_PATH` to point to `templates/shortcut-wrapper.ps1`; (2) in `write_all`, change the per-script target from `mill_dir / f"{script}.py"` to `mill_dir / f"{script}.ps1"`; (3) keep idempotency (skip when file content already matches rendered output); (4) after the write loop, add idempotent legacy cleanup — for each script in `SHORTCUT_SCRIPTS`, if `mill_dir / f"{script}.py"` exists, delete it (use `Path.unlink(missing_ok=True)`); (5) keep the return type `list[Path]` returning the paths of newly-created or overwritten PS1 wrappers (deletion is a side effect, not part of the return). Update the docstring to reflect PS1 output and the legacy cleanup. `SHORTCUT_SCRIPTS` stays unchanged — no script renames. Smoke-check by running an inline `PYTHONPATH=plugins/mill/scripts uv run --project plugins/mill python -c "from pathlib import Path; import _shortcuts; tmp = Path('.scratch/_test_shortcuts'); tmp.mkdir(parents=True, exist_ok=True); print(_shortcuts.write_all(tmp))"` and verifying `.ps1` files appear in `.scratch/_test_shortcuts/`. The inline `PYTHONPATH=` is required here because the global env var may not yet point at this dev checkout.
- **Commit:** `feat(mill): _shortcuts writes PS1 wrappers and cleans up legacy .py`
