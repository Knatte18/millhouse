**Issue:** Plan says "update all existing `test_fo_*` test invocations that call `_forward_output` directly" but none of them do — they all go through `self._call()`; an implementer following literally would update nothing and leave existing fo tests failing with `TypeError`.
**Fix:** Change instruction to "update `_call()` to accept and pass `project_root: Path = Path('/fake')` as a second argument, and add a `subprocess.run` mock context to each existing `test_fo_*` test."

### [NIT] `commit_sha` unconditionally added to stuck JSON
**Location:** 01-bugfix-batch / Card 2
**Issue:** "overwrite the `commit_sha` key in the parsed dict" uses dict assignment (`d["commit_sha"] = sha`), which adds the field even to stuck responses that have no `commit_sha`, silently contaminating the stuck contract.
**Fix:** Add "only overwrite if `'commit_sha'` is already present in the parsed dict" to the Requirements.
