## Findings

### [NIT] Card 9 omits `write_wiki_active_task_md` assertion in spawn happy-path test
**Location:** Batch 2 / Card 9, `test_main_happy_path_calls_spawn_core_in_order`
**Issue:** Every other new `_spawn_core` call (claim, capture_parent_branch, write_active_marker, write_initial_status) gets an explicit `assert_called_once()` check, but the new `write_wiki_active_task_md` call introduced in Card 5 is never asserted. A silent omission of that call would pass the test.
**Fix:** Add `sc.write_wiki_active_task_md.assert_called_once()` alongside the other `_spawn_core` helper assertions in that test.

### [NIT] Card 3 deployment note covers only mill-cleanup/mill-merge; mill-go and mill-plan are also affected
**Location:** Batch 2 / Card 3, deployment note
**Issue:** The note reads "Ensure Card 11 is run before the first `mill-cleanup` or `mill-merge` post-deploy." Batch 4 also updates mill-go (Card 16) and mill-plan (Card 15) to reference `task/plan/` and `task/status.md`. Running either skill on an unmigrated worktree will fail to find those paths for the same reason.
**Fix:** Extend the note to: "…before the first `mill-cleanup`, `mill-merge`, `mill-go`, or `mill-plan` post-deploy."

### [NIT] `_run_main_with_mocks` helper carries stale `write_initial_status.return_value`
**Location:** Batch 2 / Card 9, `test-millpy-spawn.py`
**Issue:** The helper sets `write_initial_status.return_value = Path("/fake/worktrees/my-task/status.md")` (no `task/`). Card 4 changes the real function to return `worktree_path / "task" / "status.md"`. The mock is stale. Non-failing today (nothing asserts the return value), but misleading for future readers.
**Fix:** Change to `Path("/fake/worktrees/my-task/task/status.md")` in `_run_main_with_mocks`.

### [NIT] No unit tests for `_step_rename_junctions`
**Location:** Batch 3 / Card 11
**Issue:** The migration function is the most operationally risky code in the plan (touches every active worktree, does git moves, calls write_commit_push). None of the batch 3 verify tests cover it; `run-all.py` only covers cleanup and worktree helpers.
**Fix:** Add at least one `test-migrate-rename-junctions.py` test that exercises the dry-run path and verifies the planned log entries, even if the real git operations are mocked.

## Verdict

APPROVE
Plan is architecturally sound; all four NITs are cosmetic or test-coverage gaps with no correctness impact.
