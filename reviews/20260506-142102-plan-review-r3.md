## Findings

### [BLOCKING] Code review de-blinded after batch-02 rename
**Location:** batch-field-rename / cards 7 and 11; plan files 02-field-rename.md and 03-guidance.md
**Issue:** After card 7 commits (renames `_RE_REFS_HEADER` in `_review_common.py` from `Reads|Modifies` to `Context|Edits`), every subsequent call to `parse_batch_refs` silently returns `[]` for any file that still carries `- **Reads:**` / `- **Modifies:**` headers. The task's own plan files `02-field-rename.md` and `03-guidance.md` use those headers throughout. When `_review_code.py` dispatches the code reviewer for batch 02 (after all cards are committed), it calls `parse_batch_refs` on `02-field-rename.md`, resolves no source files, and presents the reviewer with only the overview and batch file — not the 8 Python files the batch edits. Batch 02 is a mechanical rename across `_review_common.py`, `_review_plan.py`, `_review_code.py`, and `_plan_validate.py`; reviewing without those files makes the "every file listed in `Edits:` is present and matches its stated role" criterion un-checkable.
**Fix:** Add a requirement in the batch-02 scope (or insert a card between 6 and 7) mandating that the implementer updates `02-field-rename.md` and `03-guidance.md` to use `Context:` / `Edits:` field labels before committing card 7. An alternative is a card in batch 01 that pre-converts the remaining plan files while the regex still matches the old names.

### [NIT] Card 11 misidentifies one test as using hardcoded fixture text
**Location:** batch-field-rename / card 11
**Issue:** Card 11 lists `test_check_reads_not_backtick_path_none_exempt` among tests that "build batch text directly (without `_make_batch_file`)" and instructs updating its hardcoded fixture. The test actually uses `batch = _make_batch_file("alpha")` — not a raw string. The update to `_make_batch_file`'s `reads` → `context` parameter rename (also in card 11) would make the test work correctly regardless, but the description is wrong and the "three tests needing hardcoded updates" count is overstated by one.
**Fix:** Remove `test_check_reads_not_backtick_path_none_exempt` from the hardcoded-fixture list in card 11's requirements text; confirm it relies on the `_make_batch_file` parameter rename.
