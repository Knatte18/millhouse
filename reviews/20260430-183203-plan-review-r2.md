## Findings

### [NIT] `import os` missing from cards 5 and 6 requirements
**Location:** batch path-fix / cards 5–6
**Issue:** Card 5 describes an `os.name == "nt"` branch in `millpy-terminal.py` but does not say to add `import os`; the file has no such import today. Card 6 has the same gap for `_llm_claude.py`. Neither card's smoke-check will surface it: `--help` exits before reaching the platform branch (card 5), and `import _llm_claude; print('ok')` never calls `_claude_argv_prefix()` (card 6). The `NameError` would only appear during an actual script run.
**Fix:** Add "add `import os` to the file's imports if not already present" to the requirements for cards 5 and 6.

### [NIT] Card 20 requirements don't map cleanly to 4 of the 12 listed files
**Location:** batch tests-and-docs / card 20
**Issue:** `test-worktree-sibling-resolution.py` uses `MILL_SCRIPTS` (not `SCRIPTS = HUB / ...`) and defines no `HUB` variable; inserting `PLUGIN_ROOT = HUB / "plugins" / "mill"` as written would produce `NameError: name 'HUB' is not defined`. Three others (`test-go-assets.py`, `test-plan-assets.py`, `test-merge.py`) have no `[sys.executable, str(SCRIPTS / "millpy-X.py")]` patterns to replace, so the `PLUGIN_ROOT` constant would be dead code.
**Fix:** Add a note clarifying that for files lacking the `SCRIPTS = HUB / ...` pattern or having no mill subprocess invocations, the constant addition should be adapted or omitted.

### [NIT] `sys.path.insert` left in mill-skills-from-scripts after card 17
**Location:** batch skills-sweep / card 17
**Issue:** The "How to invoke the helper" Python block in `mill-skills-from-scripts/SKILL.md` retains `sys.path.insert(0, '${CLAUDE_PLUGIN_ROOT}/scripts')`; card 17 only replaces the `Run it` invocations. This is redundant after the global PYTHONPATH env var migration and inconsistent with the design decision.
**Fix:** Add a requirement to card 17 to remove the `sys.path.insert` line from the helper-invocation block.

### [NIT] Deleted template absent from All Files Touched
**Location:** plan/00-overview.md
**Issue:** Card 2 instructs `git rm plugins/mill/templates/shortcut-wrapper.py`, but the overview's All Files Touched list omits this path.
**Fix:** Add `plugins/mill/templates/shortcut-wrapper.py` (delete) to the All Files Touched list.
