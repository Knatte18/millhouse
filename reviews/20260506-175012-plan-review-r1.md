## Findings

### [BLOCKING] Card 11: git mv fails without pre-creating task/ directory
**Location:** Batch 3 / Card 11, Step 4e
**Issue:** `git mv status.md task/status.md` fails with "destination directory does not exist" if `task/` hasn't been created first. `git mv` does not create parent directories. The card specifies no mkdir step before the four move operations.
**Fix:** Before the `git mv` loop, add `(wt_path / "task").mkdir(exist_ok=True)` (and optionally a sentinel `.gitkeep` so the empty dir is stageable); then proceed with the git mv calls as specified.

### [NIT] Card 3 Req 4: junction-stripping code has no designated implementation file
**Location:** Batch 2 / Card 3, Requirement 4
**Issue:** The requirement instructs stripping old junctions (`.millhouse/wiki`, `.others`, `.active`) before the wiki config commit, with inline Python. But Card 3's Edits: lists only `wiki/config.yaml` and `_wiki.py`. There is no script file for this operational code; Card 11 already performs identical stripping inside `--step rename-junctions`.
**Fix:** Remove Req 4's inline code snippet. Replace with: "Ensure Card 11 (`--step rename-junctions`) runs before the first `mill-cleanup` or `mill-merge` post-deploy." This clarifies the temporal dependency without orphaning code.

### [NIT] Card 11: resolve_container_path and resolve_wiki_path absent from imports requirement
**Location:** Batch 3 / Card 11, Requirement 1
**Issue:** Step 4a uses `resolve_container_path(git_root)` and `resolve_wiki_path(git_root)`, but Req 1 only adds module-level imports for `_setup`, `_spawn_core`, `_gitignore`, `_config`. The existing `from _paths import resolve_main_worktree_root, resolve_git_root` line needs to be extended.
**Fix:** Add `resolve_container_path, resolve_wiki_path` to the `from _paths import ...` line in Req 1.

### [NIT] Card 11, Step 4e: wiki active dir creation duplicates Card 4's helper
**Location:** Batch 3 / Card 11, Step 4e
**Issue:** Step 4e re-implements wiki active dir creation (`mkdir`, `task.md` write, `_wiki.write_commit_push`) inline. `_spawn_core.write_wiki_active_task_md(wiki_path, slug, title, ts)` (introduced in Batch 2, Card 4, which Batch 3 depends on) does exactly this.
**Fix:** Replace the inline creation block with `_spawn_core.write_wiki_active_task_md(wiki_path, slug, title, ts)`.

## Verdict

REQUEST_CHANGES
One blocking defect (git mv fails without target dir); three NITs worth addressing before implementation.
