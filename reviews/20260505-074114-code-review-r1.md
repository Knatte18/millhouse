### [NIT] Within-batch cross-card Reads+Deletes overlap produces misleading error
**Location:** `_plan_validate.py:_check_non_existent_path`
**Issue:** If a single batch has token `T` in both a Reads card and a Deletes card, `set(raw_refs) - deletes_only` removes `T` from `general_refs`, so `T` is only checked via the Deletes path (must be on disk or in creates_union). If the file doesn't exist and isn't in creates_union, the message says `"Deletes: token 'T' does not exist..."` even though the Reads reference is the motivating reference.
**Fix:** Out of scope per plan ("cross-card consistency check… flagged for a future task"). Noting for traceability.
