## Findings

### [BLOCKING] Card 11: `_timestamp` used but never imported
**Location:** Batch 3 / Card 11 (`millpy-migrate-layout.py`), Req 4e and 4f
**Issue:** `_step_rename_junctions` calls `_timestamp.now_utc_compact()` (Req 4e: `ts = _timestamp.now_utc_compact()`), but Req 1's import additions are `import _setup, _spawn_core, _gitignore, _config` — `_timestamp` is absent. The existing script uses `datetime` directly; this would raise `NameError` at runtime.
**Fix:** Add `import _timestamp` to Req 1's import list, alongside the other four helper imports.

### [NIT] Card 1: `**/plugins/*/uv.lock` removal unjustified
**Location:** Batch 1 / Card 1 (`_gitignore.py`), Req 1
**Issue:** The plan removes `**/plugins/*/uv.lock` from `GLOB_ENTRIES` with only "carry-over from initial migration" as rationale. Plugin subdirectories (`plugins/mill/`) are live Python projects with uv.lock files; if those files are untracked, removing the ignore entry risks accidentally staging them.
**Fix:** Add a one-sentence justification to Req 1 — either "plugin uv.lock files are tracked by git and unaffected by gitignore" or "they are outside the repo and this entry was dead coverage" — so the implementer can verify before removing.

### [NIT] Card 11: Token dict construction underspecified
**Location:** Batch 3 / Card 11 (`millpy-migrate-layout.py`), Req 4e and 4f
**Issue:** Both `create_hub_links` calls say "tokens includes SLUG=slug" and "hub_tokens" without specifying the full dict (`HUB_PATH`, `WIKI_PATH`, `CONTAINER_PATH`, `REPO`, `SLUG`). The implementer must infer the token set from `_build_tokens` in `millpy-spawn.py`, which is not referenced in the card's Context list.
**Fix:** Spell out the full token dict in both sub-steps, or add `millpy-spawn.py` to the Context list with a note pointing to `_build_tokens`.

### [NIT] Card 10: Inline `import os` should be module-level
**Location:** Batch 3 / Card 10 (`millpy-cleanup.py`), Req 3
**Issue:** The code block places `import os` inline inside `apply_plan`, violating PEP 8 and the project's top-of-file import convention visible in every other script in this plan.
**Fix:** Move `import os` to the module-level imports section of `millpy-cleanup.py` in the Req 3 instruction.
