### [NIT] brief_path_for is dead code
**Location:** `plugins/mill/scripts/_review_common.py:1233`
**Issue:** `brief_path_for` is defined but never referenced anywhere; CLIs use `_agent_dispatch.write_brief` and re-derive the round via `prepare()`, so this helper is unused.
**Fix:** Remove it, or wire the finalize CLIs to use it instead of re-running `prepare()` purely to recover `round`/`reviews_dir`.

### [NIT] review CLIs skip the via_psmux dispatch shim (carryover)
**Location:** `plugins/mill/scripts/_review_common.py:1339` (`load_config`)
**Issue:** `_review_common.load_config` does not call `_apply_dispatch_shim`, so a legacy `llm.claude.psmux.via_psmux: true` hub would default to `subprocess` when a review CLI resolves dispatch; only `_config.load_config` applies the shim.
**Fix:** Apply the shim in `_review_common.load_config` too if legacy configs must be honored by reviewers (not exercised by this hub, which uses `dispatch:` directly).

### [NIT] fix finalize start_sha/snapshot diverges from full (carryover)
**Location:** `plugins/mill/scripts/millpy-fix.py:188-194`
**Issue:** `full` calls `_forward_output(..., start_sha=<post-commit HEAD>)` with no snapshot, but `finalize` passes `start_sha=None` plus the fixer snapshot, so the no-JSON inferred-success fallback behaves differently between modes.
**Fix:** Reconstruct `start_sha` as `full` does and pass `snapshot_path=None` for parity (only matters when the agent omits structured JSON).
