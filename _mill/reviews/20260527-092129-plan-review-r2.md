## Findings

### [BLOCKING] Card 2 tests 1 & 2 will fail: WikiStartupError uncaught, 10s delay
**Location:** Batch 1 / Card 2, test cases (h) stale-port-reuse and (i) non-ok-health-response
**Issue:** After the health check fails, Card 1's `_ensure_daemon` falls through to `_spawn_server(wiki_path)` (patched as no-op), then enters the spawn loop: `deadline = time.monotonic() + SPAWN_TIMEOUT` where `SPAWN_TIMEOUT = 10`. With no state file and a no-op spawn, the loop polls for 10 s then raises `WikiStartupError`. The test's outer `try/except Exception` catches it and calls `fail(name, exc)` — both tests fail. Card 2 gives no instruction to patch `wiki._client.SPAWN_TIMEOUT` or to catch `WikiStartupError` before making assertions.
**Fix:** In both test cases, before calling `_ensure_daemon`, add `patch("wiki._client.SPAWN_TIMEOUT", 0.01)` to the patch stack; wrap the `_ensure_daemon` call in `try/except WikiStartupError: pass`, then assert `state_file.exists() is False` and `mock_spawn.assert_called_once()` after the except block.

### [NIT] Card 7 preamble omits `import _safe_rmtree`
**Location:** Batch 2 / Card 7, standard preamble code block
**Issue:** The preamble snippet shows only `import _junction`, but the cleanup instruction in every test case calls `_safe_rmtree.safe_rmtree(tmp, allowed_root=tmp, ignore_errors=True)`, which requires the module to be imported.
**Fix:** Add `import _safe_rmtree` to the preamble snippet, matching the `test-safe-rmtree.py` style the plan says to mirror.
