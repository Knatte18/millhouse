### [BLOCKING] `_reviewers.load` two-layer overlay not implemented (Cards 16/17/18)

**Location:** `plugins/mill/scripts/_reviewers.py:1-60` (signature unchanged)
**Issue:** `_reviewers.load(wiki_root)` still reads `wiki_root / "agents.yaml"` directly. The plan required a complete rewrite to `load(hub_dir)` that (a) loads the plugin template via `resolve_plugin_template_path("mill-agents.yaml")`, (b) deep-merges `.millhouse/agents.local.yaml`, and (c) only falls back to the wiki on a legacy hub. **Fix:** Implement Card 16 in full: new signature `load(hub_dir: Path)`, two-layer overlay with plugin template and `.millhouse/agents.local.yaml`, legacy wiki fallback only when both layers are empty.
