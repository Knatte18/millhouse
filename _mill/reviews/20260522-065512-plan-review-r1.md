## Findings

### [BLOCKING] Card 9 uses Creates: for a file that already exists
**Location:** Batch 3 / Card 9
**Issue:** `plugins/mill/unit_tests/test-review-common.py` is listed as `Creates:` but the file is one of the 17 provided context files and contains hundreds of lines of existing tests. **Fix:** Change Card 9 to `Edits: plugins/mill/unit_tests/test-review-common.py` / `Creates: none`. Rewrite the requirements to append the 5 new tests inside the existing `main()` runner block rather than scaffold a new file from scratch.

### [NIT] Card 8 omits required `_paths.resolve_container_path` mock
**Location:** Batch 3 / Card 8
**Issue:** `_apply_inplace_record` calls `_paths.resolve_container_path(hub_root)` to build the portal path. The requirements list `_subprocess_util.run` and `_junction.remove` mocks but not this one; the test will raise on the temp-dir hub_root without it.
**Fix:** Add `patch("mill_cleanup._paths.resolve_container_path", return_value=<tmp_container>)` to the mock spec for `test_apply_inplace_deletes_hub_indicator` and `test_apply_inplace_indicator_missing_ok` (the existing test in the same file, e.g. the in-place cleanup test, shows this pattern).
