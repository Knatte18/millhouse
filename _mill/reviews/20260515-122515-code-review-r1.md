## Findings

### [NIT] Spurious `# noqa: F401` on used imports in `_psmux.py`
**Location:** `plugins/mill/scripts/_psmux.py:11-14`
**Issue:** Both `import sys` and `import _subprocess_util` carry `# noqa: F401` ("unused import"), but both are genuinely used throughout the module (`sys.stderr` in `set_history_limit`, `_subprocess_util.run` everywhere).
**Fix:** Remove the `# noqa: F401` annotations from both import lines.

### [NIT] Integration test functions swallow exceptions silently
**Location:** `plugins/mill/integration_tests/test-claude-psmux.py:56-57,96-97,137-138`
**Issue:** Each test function's `except Exception as exc: return 1 if isinstance(exc, AssertionError) else 1` discards the exception message; `main()` can only print "test returned non-zero" without the actual assertion reason.
**Fix:** Let the exception propagate — remove the bare `except` in each test function and let `main()`'s outer `try/except` capture and print it via `[FAIL] {name}: {type}: {msg}`.

### [NIT] Sleep order deviates from plan in step 6
**Location:** `plugins/mill/scripts/millpy-claude-sub.py:116-119`
**Issue:** Implementation sleeps *before* `set_history_limit`; plan step 6 specifies new_session → set_history_limit → sleep (pane-stabilise).
**Fix:** Move `time.sleep(POLL_INTERVAL_S)` to after `set_history_limit(session_name, 50000)`.

## Verdict

APPROVE
Three NITs; no blocking defects — core contracts, cleanup, parsing, and test coverage are all correct.
