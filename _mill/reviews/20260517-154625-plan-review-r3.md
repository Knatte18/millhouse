## Findings

### [NIT] Card 15 intro count contradicts body
**Location:** Batch 5 / Card 15
**Issue:** Opening sentence says "Create a `unittest.TestCase` test file with **four** cases" but the body specifies six numbered test cases (1–5 + one additional `test_log_live_pid_with_stale_mtime`).
**Fix:** Change "four" to "six" in the opening sentence so the implementer doesn't stop after case 4 and miss the regression guard.

### [NIT] Card 3 docstring gap: post-snapshot capture failure eats inner_exc
**Location:** Batch 2 / Card 3
**Issue:** The new guard body stores `inner_exc`, then calls `_capture_head_sha` / `_capture_porcelain` unconditionally. If either of those raises `ReviewError` while `inner_exc` is already set, the original inner exception is silently replaced by the post-snapshot `ReviewError`. The docstring update the card requires does not mention this edge case.
**Fix:** Extend the docstring update with a note like: "If the post-snapshot capture itself raises, that error propagates; the inner exception is not chained in that case." No code change needed — clarification only.

### [NIT] Card 11 omits importlib guidance for hyphenated CLI filenames
**Location:** Batch 3 / Card 11
**Issue:** The test must call `main(argv)` directly on each CLI script, but filenames (`millpy-review-discussion.py`, etc.) cannot be imported with a bare `import` statement due to the hyphens. The plan does not explain how to load these modules (standard approach: `importlib.util.spec_from_file_location`).
**Fix:** Add a one-line note to Card 11's requirements: "Load each CLI module via `importlib.util.spec_from_file_location('millpy_review_X', Path(scripts_dir) / 'millpy-review-X.py')` — the hyphen in the filename makes normal `import` a syntax error."
