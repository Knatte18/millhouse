## Findings

### [NIT] Card 9 "keep import shutil" instruction is inaccurate
**Location:** Batch 3 / Card 9
**Issue:** The plan says "Keep the `import shutil` line — `shutil` is still used elsewhere by the files (e.g. fixture setup)." In all three target files (`test-wiki-daemon.py`, `test-wiki-store.py`, `test-wiki-sync.py`), `import shutil` appears only as an inline import immediately before each `shutil.rmtree(...)` call — there is no standalone top-level `import shutil`. After replacing both `import shutil` and `shutil.rmtree(...)` with `_safe_rmtree.safe_rmtree(...)`, no `import shutil` is needed anywhere.
**Fix:** Drop the "Keep the `import shutil` line" instruction; a competent implementer will see that `shutil` is used nowhere else, but the phrasing could cause unnecessary confusion or a spurious top-level `import shutil` being left behind.

### [NIT] Card 2 test setup omits PROTOCOL_VERSION import
**Location:** Batch 1 / Card 2
**Issue:** The test cases write a state file with `protocol_version` matching `PROTOCOL_VERSION` but the plan only lists `WikiStartupError`, `patch`, and `MagicMock` as imports to add. `PROTOCOL_VERSION` is not currently imported in `test-wiki-daemon.py`; the implementer must also add `from wiki import PROTOCOL_VERSION` (or use the literal value 2).
**Fix:** Add `from wiki import PROTOCOL_VERSION` to the list of imports in Card 2's requirements.
