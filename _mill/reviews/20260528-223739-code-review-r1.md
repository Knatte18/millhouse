## Findings

### [NIT] `print_error_envelope` missing `nit_count` field
**Location:** `plugins/mill/scripts/_review_cli.py:31`
**Issue:** `print_error_envelope` constructs the envelope dict directly, omitting `nit_count`, so pre-launch error envelopes have a different shape than `ReviewResult.to_dict()` envelopes (which now always include `nit_count`). Mill-go only reads `nit_count` on APPROVE, so there is no runtime failure, but the schema gap will surprise future readers and any new consumer that calls `envelope["nit_count"]`.
**Fix:** Add `"nit_count": 0` to the envelope dict constructed in `print_error_envelope`.

### [NIT] Redundant sub-expression in fast-forward warning condition
**Location:** `plugins/mill/scripts/_review_common.py` — `worktree_snapshot_guard` exit logic
**Issue:** `fast_forward and not added and not (removed and not fast_forward)` — the third conjunct `not (removed and not fast_forward)` is always `True` when `fast_forward is True`, so it carries no information and obscures intent.
**Fix:** Simplify to `fast_forward and not added`.
