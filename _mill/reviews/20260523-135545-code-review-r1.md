### [BLOCKING] Integration test uses system temp dir, not .scratch/

**Location:** `plugins/mill/integration_tests/test-wiki-daemon-tinydb.py:55`
**Issue:** `tmp_dir = Path(tempfile.mkdtemp())` puts fixtures in `%TEMP%`, directly violating the shared decision ("never in `/tmp/` or `%TEMP%`"); `SCRATCH = HUB / ".scratch"` is defined on line 17 but never used.
**Fix:** Replace `tempfile.mkdtemp()` with `SCRATCH / "test-wiki-daemon-tinydb"`, create it with `mkdir(parents=True, exist_ok=True)`, and remove it in `finally`.

### [NIT] Dead condition in _parse.py

**Location:** `plugins/mill/scripts/wiki/_parse.py:23`
**Issue:** `and not layer_match` is always `True` at that point — if `layer_match` were truthy the loop would have already `continue`d; the condition is dead code.
**Fix:** Drop `and not layer_match`; `if re.match(r"^# ", line):` is sufficient and clearer.

### [NIT] Docstrings explain WHAT, not WHY

**Location:** `plugins/mill/scripts/wiki/_store.py:15,20,31,44,55,65,76,82` (and `_parse.py:6`, `_render.py:4`)
**Issue:** Multi-line docstrings summarise behaviour that well-named identifiers already express ("`Return all tasks in insertion order`", "`Compute SHA256 hash of content`", etc.); shared decision says write no comments unless WHY is non-obvious.
**Fix:** Remove all docstrings that only restate the function signature or return value; keep only any that explain a hidden constraint (none of these do).
