## Findings

### [BLOCKING] Card 8 breaks existing test-safe-rmtree assertion
**Location:** Batch 3 / Card 8
**Issue:** Card 8 replaces `shutil.rmtree(str(original), ignore_errors=ignore_errors)` with `shutil.rmtree(str(original), onexc=_readonly_handler)` — dropping `ignore_errors` from the call kwargs. The existing `"ignore_errors passes through to shutil.rmtree"` test in `test-safe-rmtree.py` asserts `mock.call_args[1].get("ignore_errors") is True`; after Card 8 that kwarg is absent (`onexc=` is passed instead), so `assert ... is True` fails with `None is True → False`.
**Fix:** Add an edit to `test-safe-rmtree.py` in Card 8 (or Card 10) replacing the `ignore_errors` kwarg assertion with a check for `"onexc"` (Python 3.12+) or `"onerror"` (3.11) in the call kwargs, and verifying the `ignore_errors=True` contract is still met via the outer try/except wrapper.

### [BLOCKING] Card 5 wrong patch target for commit_push spy
**Location:** Batch 1 / Card 5 (orphan-deletion case, #384)
**Issue:** `_server.py` imports `commit_push` via `from wiki._sync import … commit_push`, binding it as a local name. `patch("wiki._sync.commit_push")` replaces the attribute in `wiki._sync` but leaves `wiki._server.commit_push` pointing to the original function; calls from `_render_and_commit_all` bypass the spy entirely — the mock is never called.
**Fix:** Change the patch target in the orphan-deletion test to `wiki._server.commit_push` (i.e., the name as bound in the importing module's namespace).

### [NIT] Card 2 contradictory cleanup instructions
**Location:** Batch 1 / Card 2
**Issue:** Requirements say both "Use `_test_helpers.safe_temp_dir` for the temp wiki directory" and "Continue to use `shutil.rmtree(tmp, ignore_errors=True)`" — these are mutually exclusive; `safe_temp_dir` is a context manager that already handles cleanup via `safe_rmtree`.
**Fix:** Clarify: new test cases should follow the try/finally + `shutil.rmtree(tmp, ignore_errors=True)` pattern of tests (a)–(f) (which Batch 3 then converts); drop the conflicting `safe_temp_dir` reference.
