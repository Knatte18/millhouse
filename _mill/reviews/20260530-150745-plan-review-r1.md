## Findings

### [NIT] Phase 8 PYTHONPATH verification still shells to PowerShell
**Location:** Batch 1 / Card 2
**Issue:** Card 2 explicitly excludes Phase 8 from edits, but Phase 8's invariant check still instructs `[System.Environment]::GetEnvironmentVariable('PYTHONPATH', 'User')` — a PowerShell spawn — while the decision is named `no-powershell-anywhere`. A running `/mill-setup` would still hit PS on verification.
**Fix:** Update Phase 8's PYTHONPATH check line to use a Python `_winenv` / `winreg` read instead, consistent with the new write path.

### [NIT] `_do_broadcast` leaves ctypes result type and timeout unspecified
**Location:** Batch 1 / Card 1
**Issue:** Requirements write `ctypes.byref(<result>)` and `<timeout-ms>` as informal placeholders without naming the ctypes type (`c_ulong` / `DWORD_PTR` nuance on 64-bit) or the timeout value in ms.
**Fix:** Specify `result = ctypes.c_ulong(0)` and an explicit timeout (e.g. 500) so the implementer has no ambiguity; risk is low since exceptions are swallowed, but the gap is unnecessary.
