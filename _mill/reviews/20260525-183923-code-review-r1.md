## Findings

### [BLOCKING] find_active_slug happy-path test missing seed_task=True
**Location:** `plugins/mill/unit_tests/test-review-common.py` (find_active_slug: on task branch block)
**Issue:** `_make_task_worktree(Path(tmpdir), "my-task", "My Task", branch_prefix="hanf/")` is called without `seed_task=True`. `find_active_slug` calls `_marker.slug_from_branch` → `wiki.list_tasks_brief` → daemon with empty TinyDB → returns `[]` → `task is None` → `MarkerError` raised → glob fallback finds nothing → `ReviewError` raised instead of returning `"my-task"`. The assertion `assert find_active_slug(wt, wiki, cfg) == "my-task"` never runs; the exception propagates and fails the test.
**Fix:** Pass `seed_task=True` to the `_make_task_worktree` call in that block (and ensure `init_wiki_repo` ran, which `seed_task=True` triggers).

### [BLOCKING] load_task_title happy-path test missing seed_task=True
**Location:** `plugins/mill/unit_tests/test-review-common.py` (load_task_title: task_title present block)
**Issue:** Same fixture pattern — `_make_task_worktree(…, "my-task", "My Task Title", …)` without `seed_task=True`. `load_task_title` calls `_marker.task_data` → `slug_from_branch` → empty TinyDB → `MarkerError` → caught → returns the fallback slug `"my-task"`. Assertion `== "My Task Title"` fails.
**Fix:** Pass `seed_task=True` to the `_make_task_worktree` call in that block.

### [NIT] test_spawn_standard/subfolder_layout use mkdtemp instead of safe_temp_dir
**Location:** `plugins/mill/unit_tests/test-millpy-spawn.py:test_spawn_standard_layout_regression`, `test_spawn_subfolder_install_destination_layout`
**Issue:** Plan Card 10 requires migrating these two tests to `with _test_helpers.safe_temp_dir() as tmpdir:` but the implementation uses `tempfile.mkdtemp() + try/finally`. Low risk (no wiki daemon spawned in these mocked tests) but contradicts the plan.
**Fix:** Replace `tmpdir = Path(tempfile.mkdtemp())` / `try` / `finally: _safe_rmtree.safe_rmtree(…)` with `with _test_helpers.safe_temp_dir() as tmpdir:`.
