## Findings

### [BLOCKING] `test_log_dead_pid_no_exit` will fail consistently on Windows

**Location:** Batch 5 (bg-liveness), Card 15

**Issue:** On Windows, `os.kill(99999999, 0)` fails via `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)`, which returns `ERROR_INVALID_PARAMETER` (87) for out-of-range PIDs; Python maps this to `OSError(errno=EINVAL=22)`. Neither `except ProcessLookupError:` (ESRCH=3) nor `except PermissionError:` (EPERM=1) catches it; the `except OSError` block also skips it (EINVAL≠EPERM, EINVAL≠ESRCH); execution falls through to the mtime fallback; the freshly-written fixture log is < 5 min old → `return (True, 99999999)`. The test asserts `(False, 99999999)` → FAIL. Since `verify: python plugins/mill/unit_tests/test-bg-liveness.py` runs on the Windows dev machine, this blocks Batch 5 completion and consequently Batch 6 (which depends on 5).

**Fix:** Annotate `test_log_dead_pid_no_exit` with `@unittest.skipIf(os.name == "nt", "os.kill dead-PID errno on Windows does not map to ESRCH — mtime path not exercisable via fresh log")`. Alternatively, use `os.utime(log_path, (old_ts, old_ts))` to backdate the log mtime > 5 min so the function reaches `(False, pid)` via the Windows-safe mtime branch, making the test platform-independent without skipping it.

### [NIT] Card 11 infrastructure mocking is underspecified

**Location:** Batch 3 (review-error-envelope), Card 11

**Issue:** The three CLI `main()` functions call `resolve_wiki_path(project_root)`, `load_config(...)`, `_reviewers.load(...)`, and `_reviewers.validate_role_refs(...)` before reaching `find_active_slug` or the backend `run()`. In a bare temp/test directory these all fail; the CLI returns 1 with a pre-launch envelope before the engine fires, making the engine-internal-failure and success path assertions unreachable regardless of what `<backend>.run` is patched to return. The requirements list only `<backend>.run` and `find_active_slug` as patch targets.

**Fix:** Add to the requirements: also patch `_paths.resolve_wiki_path` (return a dummy Path), `_review_common.load_config` (return a minimal cfg dict), `_reviewers.load` (return `{}`), and `_reviewers.validate_role_refs` (no-op) so execution reaches the `try: slug = find_active_slug(...)` block where the per-test stubs take effect.

### [NIT] Dead errno branches in `is_bg_worker_alive`

**Location:** Batch 5 (bg-liveness), Card 14

**Issue:** In Python 3.3+, `OSError` instances with `errno.ESRCH` are automatically promoted to `ProcessLookupError` and those with `errno.EPERM`/`EACCES` to `PermissionError`. The `except ProcessLookupError:` and `except PermissionError:` clauses above already exhaust these cases, so `if exc.errno == errno.EPERM: return (True, pid)` and `if exc.errno == errno.ESRCH: return (False, pid)` inside the `except OSError` branch are unreachable dead code.

**Fix:** Remove both `if exc.errno ==` branches and replace with a single comment: `# Unknown errno from os.kill (Windows-specific or transient) -- fall through to mtime fallback.`
