## Findings

### [NIT] Card 8 uses "Creates" for an existing file
**Location:** Batch 3 / Card 8
**Issue:** `test-wiki-store.py` already exists in the repo (provided in context) with old-API tests (`Store()` no-arg, `invalidate_all()`); the card says "Creates:" not "Edits:", which may cause an implementer to treat the file as absent rather than replacing it.
**Fix:** Change `Creates: test-wiki-store.py` to `Edits: test-wiki-store.py` and note the existing file must be fully replaced.

### [NIT] "Register in run-all.py" instruction is wrong
**Location:** Batch 3 / Cards 7 and 8
**Issue:** Both cards say "Register `test-wiki-*.py` in `run-all.py` by adding it to the test list" — but `run-all.py` uses `HERE.glob("test-*.py")` auto-discovery; there is no explicit test list to add to.
**Fix:** Replace the registration instruction with: "No edit needed — `run-all.py` auto-discovers all `test-*.py` files by glob."

### [NIT] Card 6 Step 2 references private Store attribute
**Location:** Batch 2 / Card 6, Step 2
**Issue:** "or if `_initialized` is False" requires the server to read `self._store._initialized` (private), which breaks encapsulation.
**Fix:** Rewrite the condition as "or if `self._store.get('Home.md') is None`" — the public contract already guarantees `get` returns `None` when uninitialized.
