## Findings

### [BLOCKING] Card 8 plan-review guard unreachable; Card 11 test will fail

**Location:** Batch 2 Card 8 + Batch 3 Card 11
**Issue:** `_review_plan.py` already contains `if holistic_name is None or cfg["roles"]["plan-review"]["holistic"]["rounds"] == 0: holistic_spec = None`, so when `holistic.rounds = 0` is set in config the holistic block is skipped before Card 8's guard can fire. Card 11's test sets `holistic rounds = 0` in config and asserts `r.round == 0`, but batch reviews (reviewer = `test_stub`, rounds = 3) still run and produce `round >= 1`, failing the assertion.
**Fix:** Card 11's plan-review test must trigger the guard via the `max_rounds=0` kwarg (not config), with `holistic reviewer` set to non-null and config rounds non-zero so `holistic_spec` is not nulled out; additionally, drop or correct the `r.round == 0` assertion since batch reviews run before the holistic guard returns — or disable the batch reviewer in the fixture to get a reviews-empty result.

### [BLOCKING] Card 15 Fix 1 passes wrong second argument to `_config.load_config`

**Location:** Batch 4 Card 15
**Issue:** The plan instructs `_config.load_config(worktree_root, worktree_root / ".millhouse")`, but `_config.load_config`'s second parameter is `worktree_root` (the git root), and the function internally appends `.millhouse`; passing `worktree_root / ".millhouse"` causes the function to look for `.millhouse/.millhouse/config.local.yaml`, silently skipping the local config layer.
**Fix:** Change to `_config.load_config(worktree_root, worktree_root)`.

### [NIT] Card 1 produces duplicate exit-code-timeout breadcrumb on Windows

**Location:** Batch 1 Card 1
**Issue:** `_run_windows_watchdog` already emits `[subprocess] exit code=timeout duration=...` before raising `TimeoutExpired`; Card 1's plan adds a second emit of the same line in `run()`'s outer except block, producing a duplicate on Windows timeout paths.
**Fix:** For the Windows watchdog except block, emit only `_spawn_msg` (the spawning breadcrumb), not the exit-code line; the watchdog has already printed it.

### [NIT] Card 15 Fix 2/3 error message hardcodes wrong path

**Location:** Batch 4 Card 15
**Issue:** The fallback halt message reads "Run 'uv sync --project plugins/mill' manually" which is incorrect when `PLUGIN_ROOT` is the installed cache path.
**Fix:** Replace the literal `plugins/mill` in the message with `${PLUGIN_ROOT}`.

## Verdict

REQUEST_CHANGES — two blocking defects: the plan-review `rounds=0` test/implementation mismatch (Card 8 + Card 11) will produce a failing test, and the wrong `load_config` argument in Card 15 silently skips local config.
