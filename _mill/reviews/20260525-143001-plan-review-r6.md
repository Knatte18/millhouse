### [NIT] Card 8 wiki-failure test patches global module state via direct assignment
**Location:** Batch 5 / Card 8 (`05-test-sweep-heavy.md`)
**Issue:** Assigning `mill_fold.wiki.upsert_task = _failing_upsert` mutates the live `wiki._client` module attribute globally. If an assertion fires before the `finally` restore block runs, subsequent tests in the same process will see the broken stub. The plan acknowledges this risk and recommends `unittest.mock.patch.object` as the safer form.
**Impact:** Minimal if the `finally` is always present, but the manual pattern is fragile. Prefer `with patch.object(mill_fold.wiki, "upsert_task", side_effect=WikiPushError(...)):` as a context manager to guarantee restoration.
