## Findings

### [BLOCKING] test_apply_worktree_deletes_hub_indicator missing resolve_container_path mock
**Location:** `plugins/mill/unit_tests/test-cleanup.py` — `test_apply_worktree_deletes_hub_indicator` block
**Issue:** `mod._apply_worktree_record` calls `_paths.resolve_container_path(hub_root)` where `hub_root = tmp / "hub"` (a bare temp dir, not a container-form repo). The plan card 8 explicitly requires mocking `mill_cleanup._paths.resolve_container_path` for this test; the implementation omits it. If `resolve_container_path` raises for non-container paths (consistent with how every other direct test of `_apply_inplace_record` mocks it), the assertion on indicator deletion is never reached and the test silently fails or errors.
**Fix:** Add `with patch("mill_cleanup._paths.resolve_container_path", return_value=tmp / "container"):` around the `_apply_worktree_record` call, matching the pattern used in `test_apply_inplace_deletes_hub_indicator`.

### [NIT] __import__ in glob-fallback tests instead of top-level import
**Location:** `plugins/mill/unit_tests/test-review-common.py` — three `find_active_slug` glob-fallback blocks near end of `main()`
**Issue:** Each `side_effect` uses `__import__('_marker', fromlist=['MarkerError']).MarkerError("test")`. The file already imports `_review_common` which binds `_marker` internally; a plain `import _marker` at the top (matching the file's other test conventions) and `_marker.MarkerError("test")` is cleaner and consistent with the plan's phrasing.
**Fix:** Add `import _marker` alongside other top-of-file script imports; replace `__import__(...)` calls with `_marker.MarkerError("test")`.

## Verdict

REQUEST_CHANGES — one plan-required mock is missing; the worktree indicator test may not verify its assertion.
