## Findings

### [BLOCKING] test-review-cli-error-envelope.py missing sys.path setup
**Location:** `plugins/mill/unit_tests/test-review-cli-error-envelope.py:1-12`
**Issue:** The file has a comment `# Add scripts dir to path for imports` and defines `scripts_dir` but never imports `sys` and never calls `sys.path.insert(0, str(scripts_dir))`. Every `patch("_paths.resolve_wiki_path", ...)`, `patch("_review_common.find_active_slug", ...)`, and `from _review_common import ReviewResult` inside the test methods requires `_paths`/`_review_common` to be importable. Without the `sys.path` insert, running the test standalone or via `run-all.py` fails with `ModuleNotFoundError` at the first `patch(...)` call. Every other test file in the suite (`test-bg-liveness.py`, `test-review-common-guard.py`, `test-wiki-noop-commit.py`, `test-llm-claude-argv.py`) has the canonical `import sys` + `sys.path.insert(0, str(HUB / "plugins" / "mill" / "scripts"))` block.
**Fix:** Add `import sys` to the stdlib imports block and add `sys.path.insert(0, str(scripts_dir))` immediately after the `scripts_dir = ...` assignment.

### [NIT] test-bg-liveness.py final block uses tab instead of spaces
**Location:** `plugins/mill/unit_tests/test-bg-liveness.py` (last two lines)
**Issue:** The `if __name__ == "__main__":` block uses a hard tab before `unittest.main()` while every other indented line in the file (and every sibling test file) uses 4-space indentation.
**Fix:** Replace the tab with four spaces: `    unittest.main()`.
