## Findings

### [BLOCKING] Integration tests omitted from `verify:`
**Location:** Batch 1 Card 4, Batch 2 Card 8
**Issue:** Both new integration test files (`test-subprocess-tree-kill.py`, `test-millpy-bg-detached.py`) are explicitly excluded from their batch's `verify:` command; per review criteria this is BLOCKING regardless of the documented rationale.
**Fix:** Append each test to its batch's `verify:` — the existing `if os.name != "nt": sys.exit(0)` skip-guard makes it a no-op on POSIX, so CI on non-Windows is unaffected; the Windows coverage gap is closed for operators who do run `verify:` locally.

### [NIT] Card 8 subprocess spawn missing PYTHONPATH
**Location:** Batch 2 Card 8
**Issue:** The requirements spawn `millpy-bg.py` via bare `sys.executable`; the launcher-mode path imports `_subprocess_util` (not on the default PATH), so the subprocess exits with `ModuleNotFoundError` before printing `pid=... log=...`.
**Fix:** Pass `env={**os.environ, "PYTHONPATH": str(HUB / "plugins" / "mill" / "scripts")}` in the `Popen` call, matching the env-injection pattern; or invoke via `uv run --project` as `test-spawn.py` does.
