## Findings

### [BLOCKING] Fixture path resolution unspecified in Card 3
**Location:** Batch 2, Card 3 Requirements — artefact construction
**Issue:** Requirements say "read `fixtures/sample-discussion.md`" (and `fixtures/sample-plan/00-overview.md`, `fixtures/sample-plan/01-core.md`, `fixtures/sample-code.py`) without specifying a base path; the verify command runs from the repo root, so a CWD-relative `fixtures/...` resolves to a non-existent path and the verify fails with `FileNotFoundError`.
**Fix:** State that fixture paths are resolved as `Path(__file__).parent / "fixtures" / "..."` — the sys.path.insert line already uses `Path(__file__).parent.parent`, establishing the pattern for this script.

### [NIT] `render_prompt` loop-placement note missing for PLAN and CODE artefacts
**Location:** Batch 2, Card 3 Requirements — artefact construction section
**Issue:** The section header says "compute once before the reviewer loop" and covers all three artefact types, but only the DISCUSSION bullet adds "Note: reviewer_model changes per reviewer — render inside the reviewer loop"; PLAN and CODE bullets omit this note, risking an implementer rendering those prompts once with a stale or hardcoded reviewer_model value.
**Fix:** Add the same note to the PLAN and CODE artefact bullets, or restructure the section header to explicitly distinguish pre-loop `artefact_section` construction from per-loop `render_prompt` calls.

### [NIT] Batch 2 verify uses bare `python`; inconsistent with batch 3 and CLAUDE.md convention
**Location:** Batch 2 header (`verify:`) and Batch Tests section
**Issue:** `python plugins/mill/integration_tests/bench-reviewers.py --reviewers test_stub --types discussion` relies on the system Python having PyYAML; batch 3 correctly uses `uv run --project plugins/mill python ...` to guarantee mill-venv dependencies, but batch 2 does not, diverging from both batch 3 and the CLAUDE.md source-tree invocation convention.
**Fix:** Change the batch 2 `verify:` command to `uv run --project plugins/mill python plugins/mill/integration_tests/bench-reviewers.py --reviewers test_stub --types discussion`.

### [NIT] Batch Tests description references junction path `.wiki`
**Location:** Batch 1, Batch Tests section
**Issue:** Batch Tests prose says "verify runs `_reviewers.load(Path('.wiki'))`" but the actual verify command uses `resolve_wiki_path(resolve_git_root())`; `.wiki` is an NTFS junction and CLAUDE.md explicitly forbids scripts from using junction paths.
**Fix:** Update the Batch Tests prose to match the actual verify expression (`_reviewers.load(resolve_wiki_path(resolve_git_root()))`) to avoid implying junction paths are acceptable for script use.
