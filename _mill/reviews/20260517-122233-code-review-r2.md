### [NIT] test-review-guard.py: main() returns raw error count, not binary 0/1; missing final summary print

**Location:** `plugins/mill/unit_tests/test-review-guard.py` — `main()` return statement and end of function

**Issue:** Every other test file in the suite (`test-review-plan-flow.py`, `test-review-code-flow.py`, `test-review-discussion-flow.py`) follows the pattern: `return 1` if any errors, print `"All X tests passed."` on success, `return 0`. `test-review-guard.py` returns `errors` directly (could be 2, 3, etc.) and has no terminal success print. ### [NIT] test-llm-claude.py: bulk _build_argv assertion weaker than plan specified

**Location:** `plugins/mill/unit_tests/test-llm-claude.py` — bulk `_build_argv` assertion block

**Issue:** The plan specified `assert argv[-2:] == ["--disallowedTools", "Edit,Write,Bash,NotebookEdit"]` to verify positional placement at the end of the argv list. The implementation uses `assert "--disallowedTools" in argv and "Edit,Write,Bash,NotebookEdit" in argv` which only checks presence, not position. Functionally equivalent but the weaker form would not catch a future regression where the deny-list value appears as a non-adjacent element.

**Fix:** Tighten to the positional form: `dt_idx = argv.index("--disallowedTools"); assert argv[dt_idx + 1] == "Edit,Write,Bash,NotebookEdit"` (consistent with the tool-use and run_bulk assertions already in the file).
