## Findings

### [NIT] env-var precedence: argv overrides explicit env "600"
**Location:** `plugins/mill/scripts/wiki/_server.py:332-340`
**Issue:** Logic uses `if idle_timeout == 600 and len(sys.argv) > 2:` to decide argv fallback. If `WIKI_DAEMON_IDLE_TIMEOUT="600"` is set explicitly, argv still wins — minor deviation from plan precedence "env → argv → 600". Harmless in practice since tests set "1".
**Fix:** Track whether env actually parsed via a sentinel (`env_set = False; ... env_set = True`) and gate argv fallback on `not env_set`.

### [NIT] test-marker.py negative tests still write V2 `[[foo]]` syntax to Home.md
**Location:** `plugins/mill/unit_tests/test-marker.py:62-66, 184-186, 212-214`
**Issue:** Three negative-path tests overwrite Home.md with V2 double-bracket form after `_make_task_worktree` returns. The V3 client reads tasks.json (not Home.md), so these tests still pass, but the V2 markup is dead/misleading.
**Fix:** Update to single-bracket `[foo] [active]` for consistency with the rest of the suite — purely cosmetic.

### [NIT] test-review-code-flow.py inline fixtures (test3, test4, test7, test12) skip seed_task pattern
**Location:** `plugins/mill/unit_tests/test-review-code-flow.py:tests 3/4/7/12 inline setup blocks`
**Issue:** These tests build their own fixtures and call `seed_wiki_config(wiki_root)` but skip `init_wiki_repo` + `wiki.upsert_task`, and still use V2 `[[{SLUG}]]` syntax in Home.md. The batch-local decision in 02-fixture-updates.md called for seeding "regardless of which layout helper the fixture uses." Tests likely pass because the daemon-spawn path tolerates a non-git wiki for read-only ops (gitignore commit failure is swallowed), but it leaves V2 markup in fresh-touch tests.
**Fix:** Add `_test_helpers.init_wiki_repo(wiki_root)` + `wiki.upsert_task(...)` after `seed_wiki_config(wiki_root)`, change `[[{SLUG}]]` → `[{SLUG}]`.
