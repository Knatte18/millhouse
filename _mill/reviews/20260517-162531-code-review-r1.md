## Findings

### [BLOCKING] test-wiki-noop-commit uses custom runner, not unittest.TestCase
**Location:** `plugins/mill/unit_tests/test-wiki-noop-commit.py:1-120`
**Issue:** The Shared Decision "Unit-test framework is unittest" mandates `unittest.TestCase` for all new tests in this task, and Card 13 explicitly says "Create a `unittest.TestCase` test file". The implementation uses a manual `main()` with `passed`/`failed` counters and `sys.stdout.buffer.write` instead of the project-standard pattern used by every other new test in this batch (see `test-llm-claude-argv.py`, `test-review-common-guard.py`, `test-bg-liveness.py`, `test-review-cli-error-envelope.py`).
**Fix:** Rewrite using `unittest.TestCase` with `def test_noop_unchanged_file`, `def test_noop_rewrite_identical_content`, `def test_real_change_commits_normally` methods and `if __name__ == "__main__": unittest.main()`.

### [NIT] Tab indentation in _bg.py and test-bg-liveness.py
**Location:** `plugins/mill/scripts/_bg.py:1-end`, `plugins/mill/unit_tests/test-bg-liveness.py:1-end`
**Issue:** Both files use hard-tab indentation; every other Python file in the repo uses 4-space indentation. PEP 8 / pycodestyle flag this as W191/E101, and it will fail any linting step added in future.
**Fix:** Replace tabs with 4-space indentation throughout both files.
