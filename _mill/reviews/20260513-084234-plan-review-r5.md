## Findings

### [NIT] Monkeypatch target underspecified in test scenarios
**Location:** Batch 1, Card 2
**Issue:** The scenarios that monkeypatch `_paths.resolve_container_path` (e.g. "refuses on path == container root") don't specify whether to patch `_safe_rmtree._paths.resolve_container_path` or `_paths.resolve_container_path` directly; both work but the former is more precise.
**Fix:** Specify `patch("_safe_rmtree._paths.resolve_container_path", return_value=container)` — or equivalently use `patch("_safe_rmtree._blacklist_for", return_value=[...])` consistently with Change B.

### [NIT] Replacement log string content not specified
**Location:** Batch 2, Card 3
**Issue:** The instruction says to eliminate `shutil.rmtree` from the log string `"[worktree] remove_safe: git failed; falling back to shutil.rmtree (junctions already stripped)"` but doesn't give the replacement text.
**Fix:** Specify the new string, e.g. `"[worktree] remove_safe: git failed; falling back to _safe_rmtree (junctions already stripped)"`.

### [NIT] Inline `import shutil` removal implicit for test-millpy-spawn.py
**Location:** Batch 2, Card 4
**Issue:** In `test-millpy-spawn.py` the three Shape B calls are inside test functions that each open with `import shutil`; after migration those inline imports become dead code. Card 4 says "verify with a regex grep" but doesn't explicitly name these inline imports.
**Fix:** Note explicitly that the per-function `import shutil` lines inside `test_spawn_standard_layout_regression`, `test_spawn_subfolder_install_destination_layout`, and `test_spawn_discovery_round_trip_subfolder` must also be removed; the module-level `import shutil` is absent so no top-level change is needed.
