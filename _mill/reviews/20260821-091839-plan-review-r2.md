### [NIT:consistency] Card 7 miscounts test-preflight.py's pre-existing test functions
**Location:** batch 2 / card 7 **Issue:** Requirements state the file "currently defines seven `test_*` functions (six pre-existing plus this card's new one)" but `test-preflight.py` actually already defines seven `test_*` functions before this card runs (verified by reading the file), not six. **Fix:** Correct the count to "seven pre-existing" (or just drop the specific number and rely on the existing "every `test_*` function in this file" instruction, which is unambiguous regardless).

### [NIT:consistency] Batch Scope's except-clause description is broader than Card 3's actual code
**Location:** batch 1 / Batch Scope + card 3 **Issue:** The Batch Scope's batch-local decision describes catching "`pygit2.GitError`/`_pygit2_util.GitOpsError`" but Card 3's own Requirements specify a single `except _pygit2_util.GitOpsError` — correct in practice since `head_sha`/`local_branches_at_sha` never let a raw `pygit2.GitError` escape (both always re-wrap into `GitOpsError`), but the two descriptions of the same fallback don't literally match. **Fix:** Reword the Batch Scope sentence to name only `_pygit2_util.GitOpsError`, matching Card 3's actual except clause.

### [NIT:design] Attribute-level check fully executes the target module rather than just checking presence
**Location:** batch 2 / card 6 **Issue:** `missing_helpers`'s new `"module:attr"` path uses `spec.loader.exec_module(module)` to check `hasattr`, meaning any future `check_helpers(["mod:attr"])` caller fully imports/executes `mod`'s top level (not just stats an attribute); confirmed harmless for this plan's two concrete call sites (`_parent_branch.py`'s only top-level import is `_subprocess_util`, no other side effects), but the general-purpose helper carries this cost for any future caller with a heavier module. **Fix:** No action required for this task; worth a one-line docstring caveat that `"module:attr"` fully imports the module, for future callers' awareness.
