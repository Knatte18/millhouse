## Findings

### [BLOCKING:scope] Summary CLI never matches per-batch code-review filenames
**Location:** 08-summary-command.md, Card 30/31 (`parse_review_filename`).
**Issue:** The spec limits the batch-scope pattern to `<ts>-plan-review-<batch-name>-r<N>.md` only. `_review_common.RE_BATCH` and `write_review_file()` both also emit `<ts>-code-review-<batch-name>-r<N>.md` for per-batch code review — the review artifact mill-go produces every batch. Card 31's test cases never exercise a per-batch code filename either.
**Fix:** Extend `parse_review_filename` (and its test cases) to accept `<ts>-code-review-<batch-name>-r<N>.md` with the batch name as scope, mirroring `RE_BATCH`'s `type=plan|code`.

### [BLOCKING:design] `_review_one_batch`'s outer ReviewError handler can read unset locals
**Location:** 06-plan-metadata.md, Card 23.
**Issue:** The single `try/except ReviewError` wrapping `_review_one_batch` (source: `_review_plan.py` lines ~170-343) covers code that can raise `ReviewError` *before* any reviewer call — the round-cap check and `resolve_ref_paths` hard-fails. Card 23 says the except block is "populated from whatever totals are in scope at raise time" but never instructs initializing `duration_s`/`tool_calls`/`cost_usd` to `None` before that code runs, so a pre-call `ReviewError` hits `UnboundLocalError`.
**Fix:** Require `duration_s = tool_calls = cost_usd = None` as the first statement inside the try block, before `round_n = discover_round(...)`.

### [NIT:consistency] Card 33's regen command bypasses the mandated cache-form invocation
**Demoted-from:** BLOCKING
**Location:** 08-summary-command.md, Card 33.
**Issue:** The card instructs `PYTHONPATH="plugins/mill/scripts" "$MILL_PYTHON" plugins/mill/scripts/millpy-skills-index.py` — a worktree-relative path. CLAUDE.md's Script invocation section mandates the `${CLAUDE_PLUGIN_ROOT}/scripts` cache form for "all operational calls," with only unit tests and mill-setup as named exceptions, and explicitly states `${CLAUDE_PLUGIN_ROOT}` "remains correct for script invocation" even for this self-hosted repo.
**Fix:** Use `PYTHONPATH="${CLAUDE_PLUGIN_ROOT}/scripts" "$MILL_PYTHON" "${CLAUDE_PLUGIN_ROOT}/scripts/millpy-skills-index.py"` (cwd still the worktree root, so `_repo_root()`'s `git rev-parse --show-toplevel` still resolves the worktree).

### [NIT:scope] Card 30 omits resolving `wiki_root` needed by `find_active_slug`
**Location:** 08-summary-command.md, Card 30.
**Issue:** `main()`'s described resolution list (git_root, hub, cfg, slug, reviews_dir, registry) never mentions resolving `wiki_root`, but `_review_common.find_active_slug(hub_root, wiki_path, cfg)` requires it as a positional arg. No CLI file demonstrating this call (e.g. `millpy-review-discussion.py`) is listed in Card 30's `Context:`, so the implementer must infer the missing step solely from `_review_common.py`'s signature.
**Fix:** Add "`wiki_root` via `_paths.resolve_wiki_path(git_root)`" to the card's resolution list.

### [NIT:consistency] Shared Decision undercounts the ReviewError sites it describes
**Location:** 00-overview.md Shared Decision "`_review_plan.py`'s file/no-file `ReviewError` inconsistency is preserved as-is".
**Issue:** The Decision says "four of the five" parse-failure `ReviewError` sites write a file. Cards 17/20/21/23/24/25 collectively specify seven such sites across the three backends (discussion.finalize, code.finalize, code.run×2, plan.finalize, plan.run-holistic, plan._review_one_batch) — six file-writing, one file-less — not five.
**Fix:** Correct the Decision's count to "six of the seven ... sites" (or otherwise reconcile the number with the cards).
