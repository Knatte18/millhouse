## Findings

### [NIT] mill-plan SKILL step 1.5 prelude uses prose, not blockquote
**Location:** `plugins/mill/skills/mill-plan/SKILL.md` — step 1.5 re-run paragraph
**Issue:** The plan explicitly requires `> ` blockquote prefix for every prelude instance (`"Use Markdown blockquote prefix > . Single sentence"`); steps 2 and 4.5 in the same file correctly use blockquote format. Step 1.5 writes the prelude as plain prose, breaking visual/format uniformity.
**Fix:** Wrap the step 1.5 prelude sentence in a `> ` blockquote prefix to match the other two sites.

### [NIT] `_mock_validation_success()` fallback references non-existent `unittest.mock.nullcontext`
**Location:** `plugins/mill/unit_tests/test-millpy-bg.py` — `_mock_validation_success()` except-ImportError branch
**Issue:** `unittest.mock.nullcontext` does not exist; the correct attribute is `contextlib.nullcontext`. The `except ImportError` fallback path is dead code in practice (scripts dir is always on `sys.path`), but if it were ever triggered it would raise `AttributeError` instead of returning no-op context managers, causing confusing test errors.
**Fix:** Replace `unittest.mock.nullcontext()` with `contextlib.nullcontext()` (import `contextlib` at the top of the function or module).

### [NIT] `test_review_cli_emits_envelope_on_reviewer_load_failure` omits error-message assertion
**Location:** `plugins/mill/unit_tests/test-review-cli.py` — `test_review_cli_emits_envelope_on_reviewer_load_failure()`
**Issue:** Unlike the config-failure and slug-failure sibling tests, this test does not assert that the injected error string (`"registry missing"`) propagates into `reviews[0]["error"]`, leaving a gap in the envelope-content contract.
**Fix:** Add `if "registry missing" not in str(envelope.get("reviews", [{}])[0].get("error", "")): ...` assertion after the verdict/type checks, matching the pattern in the other two tests.
