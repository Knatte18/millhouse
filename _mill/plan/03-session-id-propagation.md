## Batch Scope

This batch plumbs the implementer session_id through `_implementer_common._forward_output` so the inferred-success fallback path emits the real session id instead of the hardcoded literal `"unknown"` (fix for #270). All three call sites — `millpy-implement.py` initial dispatch, `millpy-implement.py` resume, `millpy-implement-holistic.py` — supply the id they already have in local scope (uuid generated by the caller, or read from batch state). The helper gains a keyword-only `session_id` parameter with default `None`, preserving every existing test fixture that doesn't pass it; the literal `"unknown"` falls out as the `or "unknown"` tail of the new fallback. The unit test `test-implementer-common.py` gets one new case asserting the plumbed session id appears in the inferred-success JSON. No production change ripples to any caller other than the three named files; `_implementer_sonnet.run`, `_llm_claude._invoke`, and `_status.py` are unaffected. This batch is independent of batches 1 and 2 — different module, different file set, no shared edits.
